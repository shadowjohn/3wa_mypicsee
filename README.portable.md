# 看快寶｜Windows x64 免安裝版

將 ZIP 完整解壓縮到資料夾，再執行 **3wa_mypicsee.exe**。不需要安裝，也不會自動修改 Windows 的預設開啟方式。

- 拖入圖片，或按 `Ctrl+O` 開檔。
- 滾輪、左右方向鍵或 Page Up／Page Down 翻圖。
- `*` 設定符合視窗的倍率；`+`／`-` 調整倍率；左鍵拖移。
- `F11` 切換全螢幕，`Esc` 退出全螢幕；`P` 切換翻圖時的拖移位置保留。
- 支援 JPG／JPEG、PNG、WebP、GIF、TIFF、BMP。GIF 與多頁 TIFF 僅顯示第一格或第一頁。

專案說明、開發文件與咪卡圖集請見 [3wa_mypicsee 專案首頁](https://github.com/shadowjohn/3wa_mypicsee)。
